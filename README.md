# Srinivasavi K — The Creative Playground

A responsive, interactive personal portfolio website built with plain HTML, CSS and JavaScript. It is designed to be easy to host and edit without a build step or paid dependencies.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local server from this folder:
   - `python -m http.server 8000`
   - Visit `http://localhost:8000`

## Included interactions
- Intro/loading screen
- Responsive navigation with active section state
- Scroll reveal animations
- Custom cursor and hero collage parallax on desktop
- Interactive timeline cards
- Project category filters
- Project detail modal
- Smooth anchor navigation
- Reduced-motion accessibility support

## Personalise before publishing
- Replace the two `YOUR PHOTO HERE` placeholders in the About section with your own images.
- Replace the graphic project thumbnails with real project images/screenshots if available.
- Add your resume PDF to this folder and update the Resume note in `index.html` to link to it.
- Check dates and details before publishing. The education timeline uses 2021–2025 for PSGiTech and 2026–present for the MBA based on the supplied information.
- Add any additional project files or case-study links to the project modal data in `script.js`.
- Optional: add a profile photo and update the Open Graph metadata for social sharing.

## Deploy
Upload the extracted folder to GitHub Pages, Netlify, Vercel static hosting, or any standard web host. No build command is required.

## Notes
- External links open in a new tab.
- Email uses a `mailto:` link.
- The site uses Google Fonts; if unavailable, system fallbacks are used.
- No contact form backend is configured. The email CTA opens the visitor's email application.


## Personal photographs
The `assets/` folder contains the personal portraits and event/competition photographs supplied for this portfolio. Replace these files or update the image paths in `index.html` to change them.
